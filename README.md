# AGR Adaptive Texture Optimizer 30

Рабочая версия 30: C++20, Qt 6/QML и libdeflate. При запуске доступны два
сценария на базе AGR RGB24: фиксированная НПМ-оптимизация до 3 MB и пакетная
автоматическая оптимизация 2K/4K без ручного лимита размера.

Интерфейс версии 30 выполнен в стиле iOS Liquid Glass: абстрактные световые
волны, полупрозрачные карточки, компактный dock, верхняя лента метрик и
единый comparison cockpit. Два синхронных окна и режим «Шторка» сохранены,
а цвет элементов управления по-прежнему адаптируется к загруженной текстуре.

## Сборка Windows

### Автоматически — готовый portable EXE

Проект содержит workflow `.github/workflows/windows-portable.yml`. После
загрузки проекта в GitHub откройте **Actions → Build Windows Portable EXE → Run
workflow**. В результате появится artifact
`AdaptiveTextureOptimizer-30-Windows-Portable`. Его нужно скачать, распаковать
и запустить `AdaptiveTextureOptimizer.exe`. Python, Qt и Visual Studio на
компьютере пользователя не нужны: необходимые Qt DLL и MSVC runtime уже лежат
рядом с EXE.

### Локально

Установите Visual Studio 2022 (Desktop development with C++), CMake, Git и Qt
6.6+ с комплектом MSVC. Затем откройте `x64 Native Tools Command Prompt`:

```bat
cmake -S . -B build -G Ninja -DCMAKE_PREFIX_PATH=C:/Qt/6.8.3/msvc2022_64 -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
C:/Qt/6.8.3/msvc2022_64/bin/windeployqt --qmldir qml build/AdaptiveTextureOptimizer.exe
```

Путь и версию Qt замените на установленные у вас. CMake самостоятельно загрузит
закреплённую версию libdeflate. Готовый EXE принимает PNG перетаскиванием на окно
или на сам файл программы.

## Один режим AGR Adaptive RGB24

Старая лаборатория из десяти режимов больше не используется. НПМ-сценарий запускает
один предсказуемый конвейер: сначала пробует lossless RGB24, затем адаптивно
уменьшает число цветовых представителей и уточняет результат бинарным поиском.
Для сложных изображений предусмотрены уровни вплоть до одного представителя,
поэтому допустимый предел размера не подменяется фиксированными 3 MB.

## Два рабочих сценария

**Оптимизация для НПМ-текстур** принимает один PNG, при необходимости готовит
рабочий 2K-эталон и всегда использует фиксированный предел 3 MB. Пользователь не
может случайно изменить обязательный для этого сценария лимит.

**Оптимизация текстур** принимает сразу несколько PNG 2K/4K и сохраняет их
разрешение. Здесь нет цели в мегабайтах: для каждого файла перебираются RGB24-
кандидаты, а самым лёгким считается только вариант, прошедший защитный порог
PSNR, средней и максимальной ошибки каналов. Ошибка одного файла отмечается в
списке и не останавливает остальные. Готовые файлы сохраняются в `compressed`,
после чего для каждого доступен отдельный сравнительный анализ.

## Изменения версии 30

- приложение всегда открывается в настоящем полноэкранном режиме;
- auto-quality использует два быстрых качественных прохода и libdeflate 7;
- НПМ и пакетную очередь можно безопасно остановить во время обработки;
- масштаб больше не отдаляется значительно дальше режима «Вписать»;
- скруглённая маска не позволяет изображению выходить углами за окно;
- тема космоса и Марс полностью удалены;
- приложение использует разные Liquid/Aurora-фоны для выбора, НПМ и batch;
- добавлены рисованные QML-иконки, не зависящие от шрифтов Windows;
- dock выполнен в стиле iOS с подсвеченным выбранным разделом;
- стекло получило движущиеся блики, дополнительные границы и свечение;
- параллакс фоновых волн и сфер усилен;
- после каждого импорта автоматически выполняется «Вписать»;
- добавлена мини-игра «Поймай каплю» со счётчиком и выключателем.

Палитра существует только внутри оптимизатора. Перед PNG-кодированием изображение
всегда разворачивается обратно в `RGB888`; финальная проверка требует PNG color
type 2 и bit depth 8, то есть настоящий RGB24. Алгоритм увеличивает число
представителей бинарным поиском, пока следующий вариант уже не помещается в
заданный размер. Это тратит доступный бюджет качественно, без возврата случайных
исходных пикселей и цветных выбросов.

## Текущий конвейер

1. Декодирование в RGB24; 8K уменьшается напрямую до 2K.
2. Lossless-поиск фильтров None/Sub/Up/Paeth/adaptive MinSum.
3. Упаковка libdeflate уровня 10.
4. Если выбранный предел не достигнут — AGR Adaptive RGB24 ищет максимально богатое
   представление, которое реально проходит лимит.
5. После каждого кандидата измеряются размер, PSNR, mean ΔRGB и max ΔRGB.
6. Финальный PNG декодируется и сверяется с выбранным RGB-массивом.

## Автоматическая проверка

GitHub Actions собирает portable-комплект, трижды проверяет запуск QML-интерфейса
и отдельно выполняет сквозной self-test оптимизации: создаёт тестовый PNG,
обрабатывает его, проверяет предел размера, RGB24 и точное декодирование результата.
